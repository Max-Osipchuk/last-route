# РЫБАЦКОЕ: ПОСЛЕДНИЙ МАРШРУТ

Психологический хоррор от первого лица в реальном Рыбацком (Санкт-Петербург).
Карта района построена из настоящих данных OpenStreetMap: 1363 здания с реальными
контурами и этажностью, все улицы с настоящими названиями.

## Как играть

Двойной клик по **play.bat** — откроется браузер с игрой.
(Нужен установленный Node.js — он уже есть на этой машине.)

Управление: **WASD** — идти, **Shift** — бежать, **F** — фонарик, **Esc** — пауза.

## Что внутри

- `data/raw/` — сырые данные OpenStreetMap (Overpass API)
- `tools/convert.mjs` — конвертер OSM → `data/map.json` (запуск: `node tools/convert.mjs`)
- `src/world.js` — постройка района: дома, дороги, ж/д, фонари, деревья, заборы
- `src/player.js` — игрок: движение, коллизии, фонарик (есть `player.noise` — уровень шума для будущего Слушателя)
- `src/fx.js` — атмосфера: живые фонари вокруг игрока, морось, ветер
- `tools/serve.mjs` — локальный сервер
- Скриншоты для отладки: `?shot&x=..&z=..&ry=..&rp=..&py=..&torch=1` в адресе

## Дизайн (утверждено 2026-06-10)

Изнанка Рыбацкого. Герой ищет пропавшего друга, цель — последний поезд метро
до полуночи. Монстры: Слушатель (слышит шум), Пустые (силуэты в окнах),
Сборщик (скриптовые погони). Финал: поезд, в котором молча сидят все пропавшие,
на схеме метро одна станция — РЫБАЦКОЕ.
